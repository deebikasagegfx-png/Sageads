# Sage Ads website recreation

React and Vite recreation of Sage Ads' home, About, Services, and Contact pages.

## Run locally

1. Install Node.js (18 or newer).
2. Run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` to create the production site in `dist/`.

The contact form validates required fields and displays a confirmation explaining that this frontend demo does not deliver messages. Use the email or telephone links for real enquiries.

## Reference assets

The public reference pages exposed their page copy and layout content, but the original logo artwork, hero artwork, client logos, and team portraits were not available as downloadable assets during this recreation. The wordmark and hero graphic are CSS-built, and client/team artwork uses restrained typographic placeholders. The original site also includes Projects and Blogs links; this version focuses on the requested Home, About, Services, and Contact routes.
